# media folder

Gets copied to "docs/media/"


 * kmacleod-action-strike-162016.mp3: Title Music by [kmacleod on Pixabay Music](https://pixabay.com/de/users/kmacleod-3979860/?utm_source=link-attribution&utm_medium=referral&utm_campaign=music&utm_content=162016)

 * input/: Controller icons from [Input Prompts by Kenney](https://www.kenney.nl) (CC0), see input/License.txt. The SVGs got a viewBox, so that they scale.

 * treasure/: Chest and coin from [Mini Dungeon by Kenney](https://www.kenney.nl) (CC0), see treasure/License.txt.

 * dungeon/: Stairs from [Mini Dungeon by Kenney](https://www.kenney.nl) (CC0), see dungeon/License.txt.

 * patterns/: Floor patterns from [Pattern Pack by Kenney](https://www.kenney.nl) (CC0), see patterns/License.txt.

 * sounds/sword-on-*.mp3: Sword hits from Freesound (CC BY 4.0), trimmed and normalized; the originals are in media-src/freesound/.
   * sword-on-wood: [Sword_Hit_Wood_1](https://freesound.org/people/gronnie/sounds/563173/) by gronnie
   * sword-on-metal, sword-on-flesh, sword-on-armor: [Whoosh+Sword_Hit Metal](https://freesound.org/people/marb7e/sounds/620353/), [Flesh](https://freesound.org/people/marb7e/sounds/620354/) and [Armor](https://freesound.org/people/marb7e/sounds/620355/) by Patrick-Raul Babinsky (marb7e)

 * sounds/beam-energy.mp3: [D64 Samplepack - FX POWERUP 31](https://freesound.org/people/Department64/sounds/524196/) by Department64 from Freesound (CC BY 4.0); the original is in media-src/freesound/. The game layers it on itself for the beam.

 * sounds/fire-strike.mp3: [SFX_MAGIC_FIREBALL_001](https://freesound.org/people/JoelAudio/sounds/77691/) by JoelAudio from Freesound (CC BY 4.0), trimmed; the original is in media-src/freesound/.
